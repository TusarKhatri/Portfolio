// LAB-002 / NETWORK SECURITY

TCP PORT & SERVICE SCANNER

Multithreaded TCP port discovery and service analysis

LAB-002
STATUS COMPLETED
LANGUAGE PYTHON
CATEGORY NETWORK SECURITY
TYPE CLI TOOL
// PROJECT OVERVIEW

A Python-based TCP port scanner designed to identify open TCP ports and determine the services running on those ports. The scanner uses concurrent threads to scan multiple ports efficiently and can collect HTTP response information from detected services.

// OBJECTIVE
01

Validate the target IP address and port range.

02

Scan TCP ports and identify open services.

03

Retrieve HTTP response information from accessible web services.

04

Generate a readable scan report.

// TECHNOLOGY STACK
PYTHON SOCKET THREADING IPADDRESS CLI NETWORKING
// SAMPLE SCAN
$ python Tcp_port_scanner.py 127.0.0.1 7888 8000

TARGET IP : 127.0.0.1
PORT RANGE : 7888 - 8000
THREADS : 50

SCAN RESULTS
[OPEN] 127.0.0.1:8000
SERVICE: Python HTTP Server

Server: SimpleHTTP/0.6 Python/3.13.7

OPEN PORTS FOUND : 1
TIME TAKEN : 1.55 seconds

SCAN COMPLETE ✓
// CAPABILITIES
01

Concurrent TCP scanning using ThreadPoolExecutor.

02

Automatic service identification using custom mappings and system service names.

03

HTTP response and server information collection from open web services.

// REPORT GENERATION

After the scan completes, the tool automatically creates a TXT report containing the target, port range, discovered services, banners, timestamps and total scan duration.

// KEY LEARNINGS
01

Understanding TCP connections and port states.

02

Using Python sockets for network communication.

03

Using concurrency to improve scanning performance.
